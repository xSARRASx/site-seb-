1 Corriger les textes

Dans WordPress : ouvre la page → bouton « Edit with Elementor » → clique le texte → corrige → bouton vert « Mettre à jour ».

2 Titre & description Google (Yoast)

Ouvre la page (Pages → la page → Modifier) → clique l'icône « Y » colorée en haut à droite → colle le Mot-clé principal, puis ouvre « Apparence de recherche » pour le Titre SEO + la Méta-description. Les 2 barres doivent être VERTES 🟢, puis Sauvegarder. (La « limace » = fin de l'URL : laisse telle quelle si déjà propre.)

3 Textes ALT des images

Clique une image → champ « Texte alternatif » → colle un de ces textes selon l'image.
