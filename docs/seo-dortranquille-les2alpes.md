## 5. SEO technique — checklist (dans WP)

- [ ] Yoast installé + assistant configuré (nom entreprise, logo, séparateur)
- [ ] Indexation activée (Réglages > Lecture : « décourager les moteurs » **décochée**)
- [ ] Permaliens « nom de l'article »
- [ ] Search Console validée + sitemap `/sitemap_index.xml` soumis
- [ ] Cache actif (LiteSpeed — site sur **Hostinger**)
- [ ] Images en WebP (Converter for Media)
- [ ] HTTPS OK, cohérence www / non-www, aucune 404
- [ ] Désactiver indexation archives auteur (site mono-auteur) / pièces jointes

> ⚠️ Le site renvoie actuellement une **erreur 403 de l'extérieur** → à vérifier :
> page « en construction », protection par mot de passe, ou pare-feu Hostinger.
> Tant que ce 403 est là, **Google ne peut pas indexer**. À lever avant la mise en ligne SEO.
