## ✅ Actions réalisées

**Configuration & technique**
- [ ] Yoast SEO installé et configuré
- [ ] Search Console validée + sitemap soumis
- [ ] Site indexable (case « décourager les moteurs » décochée)
- [ ] Permaliens « nom de l'article »
- [ ] Cache actif ([LiteSpeed / WP Rocket])
- [ ] Images converties en WebP
- [ ] HTTPS OK, cohérence www / non-www, aucune 404

**On-page (par page traitée)**
- [ ] Titles 55-60 car. (mot-clé + ville en début)
- [ ] Meta descriptions 140-155 car. (accroche + ville + CTA)
- [ ] H1 unique + structure H2/H3
- [ ] Slugs propres
- [ ] Balises ALT sur les images
- [ ] Maillage interne en place
- [ ] Feu vert / orange Yoast atteint

**SEO local**
- [ ] Fiche Google Business optimisée (catégorie, description, zone, horaires, photos)
- [ ] NAP cohérent site ↔ fiche
